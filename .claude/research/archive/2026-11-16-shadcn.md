# Research: shadcn support (2026-11-16)

The research sweep behind `.claude/plans/2026-11-16-shadcn.md`. Each claim names its source.
**Checked** claims were re-read against their source by a second agent; **reported** claims
carry a source and a quote from the researcher but were not re-checked. Facts as of 2026-11-16.

## Checked against the source

- The current npm latest stable release is shadcn 4.23.0, published on 2026-10-27, so 4.23.0 is the current exact pin candidate.
  - Source: https://registry.npmjs.org/shadcn (Registry read 2026-11-16)
- shadcn/ui publishes an official skill explicitly intended for Claude Code, and its documented installation command is `npx skills add shadcn/ui`.
  - Source: https://ui.shadcn.com/docs/skills.md (Read 2026-11-16; identical install text confirmed in official repository revision e62c9435fff729a175f38983dee73b2cb4f6a069, dated 2026-11-13.)
- The latest published @shadcncraft/skills release is 0.2.0, published on September 21, 2026.
  - Source: https://registry.npmjs.org/@shadcncraft%2fskills (Registry checked 2026-11-16)
- Biome already provides the standard rule needed for tag-level design-system enforcement: `linter.rules.correctness.noRestrictedElements`, available since v2.0.0, not recommended by default, with information severity and no automatic fix; explicitly configure `level: "error"` for enforcement.
  - Source: https://biomejs.dev/linter/rules/no-restricted-elements/javascript (Current documentation read 2026-11-16; rule available since Biome 2.0.0)
- The official server invocation is shadcn mcp, with the documented package-runner configuration using npx and arguments ["shadcn@latest", "mcp"], not a separate MCP-server package.
  - Source: https://ui.shadcn.com/docs/mcp (Official docs read 2026-11-16)
- The official skill is project-aware rather than a fixed component recipe: its documentation says it reads components.json and obtains framework, aliases, installed components, icon library and base library.
  - Source: https://ui.shadcn.com/docs/skills.md (Read 2026-11-16; page has no explicit update date.)
- Redistributing the skills and installer in an open plugin is permitted by their MIT license, provided the copyright and permission notices accompany copies or substantial portions.
  - Source: https://raw.githubusercontent.com/shadcncraft/skills/4b985dad2d26dd2d83bebb5fc28e0344d0021b8b/LICENSE (Copyright 2026; source revision 4b985dad2d26dd2d83bebb5fc28e0344d0021b8b; matches published 0.2.0 LICENSE)
- Biome's `options.elements` is a map from element names to diagnostic messages, so a project can prohibit `select`, `table`, `input`, `textarea`, and `dialog` with messages naming its replacements, without installing another lint plugin.
  - Source: https://biomejs.dev/schemas/2.5.15/schema.json (Biome 2.5.15 versioned schema; independently confirmed in installed schema)

  - Source: https://raw.githubusercontent.com/shadcn-ui/ui/e62c9435fff729a175f38983dee73b2cb4f6a069/skills/shadcn/SKILL.md (Repository revision e62c9435fff729a175f38983dee73b2cb4f6a069, dated 2026-11-13; skill file last changed 2026-10-14.)

  - Source: https://raw.githubusercontent.com/shadcncraft/skills/4b985dad2d26dd2d83bebb5fc28e0344d0021b8b/LICENSE (2026; matches published 0.2.0 LICENSE)

  - Source: https://biomejs.dev/schemas/2.6.8/schema.json (Biome 2.6.8; matching options also read in 2.5.15)

  - Source: https://shadcncraft.com/license (Live license checked 2026-11-16; no effective date shown)

  - Source: https://biomejs.dev/reference/configuration/#overrides (Documentation read 2026-11-16; configuration also tested with installed Biome 2.5.15)

  - Source: https://ui.shadcn.com/docs/registry/github ; https://github.com/shadcn-ui/ui/blob/shadcn%404.23.0/packages/shadcn/src/mcp/index.ts (Official docs read 2026-11-16; MCP integration checked in shadcn 4.23.0)
